# مرجع صنعت

تحلیل صنعت، محیط رقابتی، وابستگی‌ها و گونه‌های مرتبط را یکجا توضیح می‌دهد؛
نگاشت به چند کلاس فعالیت ممکن است. صنعت با یک Section رسمی برابر فرض نمی‌شود.
رکورد `industry` و مسیر `industries/<id>.md` در [فهرست رسمی](../catalog.json)
ثبت می‌شود. تا نیاز واقعی، صفحهٔ صنعت ساخته نمی‌شود. [معماری](../docs/architecture.md)
مرز و رابطه‌ها را تعیین می‌کند.
