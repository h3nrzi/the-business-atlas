# اطلس کسب‌وکار — The Business Atlas

**A Comprehensive Encyclopedia of Modern Businesses**
دانشنامهٔ جامع کسب‌وکارهای مدرن · زبان اصلی: فارسی (fa-IR) · گستره: جهان

اطلس کسب‌وکار مرجعی آموزشی و پیوسته در حال تکامل برای شناخت فعالیت‌های اقتصادی
است: یک کسب‌وکار چرا وجود دارد، چگونه ارزش می‌آفریند، چگونه اداره می‌شود و با چه
محدودیت‌هایی روبه‌روست؟ اصطلاحات تخصصی با معادل دقیق انگلیسی همراه می‌شوند.
تحلیل نرم‌افزار لایه‌ای مکمل برای فهم نیازهای کسب‌وکار است.

این مخزن اکنون زیرساخت نگارش و پژوهش را دارد؛ هنوز فصل کسب‌وکاری تألیف یا منتشر
نشده است. واردکردن طبقه‌بندی اقتصادی به معنی پوشش کسب‌وکارهای جهان نیست.

## مشارکت و پژوهش

از [راهنمای مشارکت](CONTRIBUTING.md) شروع کنید. ساختار داده و مرز مفاهیم در
[معماری دانش](docs/architecture.md)، ضوابط شواهد در [روش پژوهش](docs/research.md)
و معیار انتشار در [گردش تحریریه](docs/editorial.md) تعریف شده‌اند.

برای نخستین بررسی کسب‌وکار، ابتدا [راهنمای ادغام Wayfinder](docs/workflows/wayfinder.md)
را بخوانید و از متن نمونهٔ همان راهنما استفاده کنید؛ این متن خودبه‌خود بررسی‌ای
را آغاز نمی‌کند. انتخاب موضوع و تصمیم‌های تحلیلی به عهدهٔ مالک انسانی پروژه است.

## بررسی محلی

Python 3.11 یا جدیدتر، بدون وابستگی خارجی:

```sh
python3 scripts/atlas.py check
python3 -m unittest discover -s scripts/tests -v
```

[راهنمای ابزارها](scripts/README.md) و [گزارش پذیرش زیرساخت](docs/infrastructure-acceptance.md)
مرز آزمون ساختاری و ارزیابی انسانی را توضیح می‌دهند. انتشار وب‌سایت، کتاب و دوره
در این مرحله پیاده‌سازی نشده است.

## حقوق استفاده

برای محتوای تألیفی هنوز مجوز بازنشر عمومی انتخاب نشده است؛ مشاهدهٔ عمومی مخزن
به‌تنهایی مجوز استفادهٔ مجدد نیست. حقوق داده‌ها، مهارت‌های نصب‌شده و منابع خارجی
مستقل است؛ [سیاست حقوق و استناد](docs/research.md#rights) را ببینید.
