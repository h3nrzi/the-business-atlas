# منابع و شواهد

[registry.json](registry.json) شناسنامهٔ یکتای منبع و [سیاست پژوهش](../docs/research.md)
معیار استفاده است. ادعای خاص و صفحه/بند شاهد در دفتر شواهد کنار فصل نگه‌داری
می‌شود. [بررسی ISIC](isic-rev5-research.md) تنها پژوهش زیرساختی این مرحله است؛
هیچ پژوهش کسب‌وکار انجام نشده است. فایل‌های حقوق‌دار صرفاً به دلیل دسترسی عمومی
در این پوشه کپی نمی‌شوند.
