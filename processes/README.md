# فرایندهای مشترک

رکورد `process` در [فهرست](../catalog.json) و متن `processes/<id>.md` نگه‌داری
می‌شود. تعریف شامل محرک، نتیجه، نقش، ورودی/خروجی، گام‌ها، کنترل، استثنا، سنجه و
محدودیت است. فرایند قابلیت سازمانی نیست؛ [واژگان](../GLOSSARY.md) را ببینید.
کاربرد و تفاوت محلی در فصل گونه می‌ماند. چارچوب حفاظت‌شدهٔ خارجی بازتولید نمی‌شود.
