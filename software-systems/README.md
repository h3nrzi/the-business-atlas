# تحلیل مکمل سامانه‌ها

این بخش نیاز کسب‌وکار را تحلیل می‌کند، نه محصول فرضی می‌سازد. هر رکورد
`software-system` با `relations.businesses` به گونه‌های مرجع وصل است و مسیر
`software-systems/<id>.md` دارد. [قالب](../templates/software-analysis.md) مسئله،
اطلاعات، قواعد، مسئولیت، گزینهٔ بدون نرم‌افزار و سناریوی پذیرش را پوشش می‌دهد.
همهٔ گونه‌ها الزاماً به سند مستقل نرم‌افزاری نیاز ندارند.
