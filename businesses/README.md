[catalog.json](../catalog.json) خوانده می‌شود. فصل canonical در
`businesses/<id>/index.md` است؛ دفتر شواهد، تصمیم و بازبینی کنار همان فصل می‌مانند.

استفاده کنید. این پوشه فهرست شرکت‌ها یا کپی کلاس‌های ISIC نیست.
