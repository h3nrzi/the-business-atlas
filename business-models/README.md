# مدل‌های مشترک

مدل کسب‌وکار و مدل درآمد مفهوم مستقل‌اند؛ برای اولی `business-model` با `bm-`
و برای دومی `revenue-model` با `rm-` در [فهرست](../catalog.json) ثبت می‌شود.
هر متن در `business-models/<id>.md` تعریف، شرایط کاربرد، منطق ارزش یا درآمد،
مصالحه، استثنا و منبع دارد. فصل گونه کاربرد خاص را شرح می‌دهد و تعریف مشترک را
پیوند می‌دهد. هنوز هیچ توضیح مدل واقعی تألیف نشده است.
