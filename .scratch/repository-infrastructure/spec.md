# Repository infrastructure — agreed specification

Source: user implementation request in this chat, 2026-10-18.
Scope: preserve existing skills/tracker; establish charter, knowledge architecture,
ISIC Rev.5 foundation, 26-dimension chapter contract, complementary software analysis,
research/citation/rights, learning, editorial lifecycle, actual Wayfinder integration,
canonical catalog, generated root navigation/progress, minimal validation and tests,
acceptance review, commit and normal push. No actual business chapter or investigation.

Acceptance groups: repository compatibility; classification integrity with explicit
partial-import fallback; knowledge architecture; editorial infrastructure; Wayfinder
readiness; operational quality. See permanent docs/infrastructure-acceptance.md for
criterion evidence and local acceptance guide for human observations.

Accepted implementation boundary: full official source audited; full redistribution
permission not established. No copyrighted hierarchy is distributed on an assumed
open license. Empty committed taxonomy and explicit missing portions are permitted
by the user's partial-import fallback. Local audit is separate from repository coverage.
