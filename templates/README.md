# قالب‌های نگارش

این فایل‌ها محتوای منتشرشده یا رکورد فهرست نیستند. هنگام کپی، متن راهنما و
placeholderها را با تحلیل واقعی جایگزین و پیوندهای نسبی را متناسب با مقصد اصلاح کنید.

| قالب | کاربرد |
| --- | --- |
| [فصل جامع](business-chapter.md) | قرارداد ۲۶ بُعد و عمق متناسب |
| [رکورد فهرست](catalog-record.json) | فرادادهٔ canonical؛ شناسه فقط پس از بررسی تکرار تخصیص یابد |
| [تحلیل نرم‌افزار](software-analysis.md) | لایهٔ مکمل نیاز و سناریوی پذیرش |
| [شواهد](evidence.md) | نگاشت ادعا به شاهد و محدودیت |
| [بازبینی](review.md) | gateها و ثبت واقعی اجازهٔ انسانی |
| [تحویل](handoff.md) | ادامه از آخرین حالت، نه کشف مجدد |
| [یادگیری شخصی](learning-record.md) | مشاهدهٔ یادگیرنده، مستقل از انتشار |

برای فصل آینده مسیرهایی مثل `businesses/<id>/index.md` تنها پس از انتخاب موضوع
واقعی ایجاد شوند. الگوی JSON به خودی خود شناسه‌ای رزرو نمی‌کند.
